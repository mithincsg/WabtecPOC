"""Information contained in this document is proprietary and confidential to,
and the trade secret of, Wabtec Railway Electronics of Germantown, Maryland.

This file contains constants used by the Script Engine Interface (see
``ScriptEngine.py``).  It defines the simulators that the framework can open,
manage, and connect to over the Script Engine SCM (telnet) channel.

------------------------------------------------------------------------------
How to pick the correct simulator key
------------------------------------------------------------------------------
A test that needs a simulator which is *not* already part of the running test
setup enables it from a test script with::

    run_test.enable_optional_sim("UP_OFFICE")           # single sim
    run_test.enable_optional_sim(["NS_OFFICE", "CHM"])  # several sims

``enable_optional_sim()`` forwards the value(s) to
``ProjectVariables.set_optional_sim()``, which only accepts the *keys* defined
in this file (offices, IVOCs, and the explicit optional list in
``set_optional_sim``).  The value passed is therefore always a **key** from
``sim_process_name`` below (for example ``"UP_OFFICE"``), never a process name
such as ``"UP_OfficeSimulator"`` and never a port number.

To answer "which key do I pass?":

1.  Find the simulator / external system named in the requirement in the
    grouped comments below (office, Wayside, EOT, ITO, KSD, etc.).
2.  Use the dictionary **key** shown for that simulator.  Keys are
    case-insensitive at the ``enable_optional_sim`` boundary (they are
    upper-cased), but the canonical spelling is what appears here.
3.  Keys are **not** interchangeable across railroads/offices or across
    client/server halves of a feature.  When a feature spans several
    processes (client + server, EMS + ITO, message + service, etc.) every
    required key must be enabled together - the grouped notes call this out.

------------------------------------------------------------------------------
The three structures and how they relate
------------------------------------------------------------------------------
``all_sims``
    A flat list of every simulator *process / application name* the framework
    is aware of.  These are executable/window names, not test-facing keys.
    It is a lookup/reference set of "recognized simulators"; test scripts do
    not pass these strings to ``enable_optional_sim()``.

``sim_process_name``
    Maps the **test-script-facing key** (e.g. ``"UP_OFFICE"``) to the
    **process / application name** that Script Engine opens, kills, restarts,
    and checks for (e.g. ``"UP_OfficeSimulator"``).  ``ScriptEngine.start_app``,
    ``kill_app``, and ``restart_app`` resolve the key through this dict, and
    ``is_sim_open`` checks the resulting process name.  This is the
    authoritative list of valid keys.  The ``"CROSSING"`` entry is special: its
    value is a dict keyed by SCAC that maps to a *list* of crossing process
    names.

``sim_scm_port``
    Maps the **same key** to the TCP port Script Engine uses to open an SCM
    connection to that simulator (``connect_scm`` reads it via
    ``add_module(<key>, "", <port>)``).  A key only appears here if the
    simulator supports an SCM connection.  A value of ``0`` means the simulator
    is started/managed but is not connected over SCM (e.g. ``CDU``, ``OBCDDS``,
    ``EMM``).  A key present in ``sim_process_name`` but absent from
    ``sim_scm_port`` is opened/managed only and never SCM-connected.

Verified against ``ScriptEngine.py`` (``connect_scm``/``start_app``/``kill_app``)
and ``Run_Test.py`` / ``ProjectVariables.set_optional_sim`` before writing.

:Author: dmmclean@wabtec.com; dleon@wabtec.com
:group: private
"""
